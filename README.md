# 🎬 Netflix vs Disney+ 콘텐츠 데이터 분석 및 비교 (EDA)

본 프로젝트는 글로벌 OTT 서비스인 **Netflix**와 **Disney+**의 데이터를 바탕으로 콘텐츠 구성, 타겟 연령층, 업로드 추이 등을 비교 분석한 빅데이터 프로젝트입니다.

## 📌 1. 프로젝트 개요
- **목적**: 두 OTT 플랫폼의 콘텐츠 전략 차이 분석
- **도구**: Google Colab, Python (Pandas, Numpy, Matplotlib, Seaborn)
- **데이터셋**: Kaggle의 Netflix/Disney+ 메타데이터 (CSV)

## 🛠️ 2. 분석 프로세스
1. **데이터 수집 및 병합**: 두 플랫폼의 개별 CSV 데이터를 불러와 `platform` 컬럼을 생성 후 통합
2. **데이터 전처리**: 
   - 감독(Director), 배우(Cast) 등 결측치를 'Unknown'으로 대체
   - 날짜 데이터(`date_added`)를 datetime 객체로 변환하여 시계열 데이터 추출
3. **데이터 변환**: 복잡한 관람 등급(Rating)을 '키즈, 청소년, 성인'의 3개 그룹으로 재분류
4. **데이터 시각화**: 유형별분포, 연도별 성장 추이, 타겟 연령층 분포, 러닝타임 밀도 분석

## 💡 4. 최종 결론
- **넷플릭스**: '양과 다양성' 전략. 전 연령층을 아우르되 특히 성인/청소년 콘텐츠의 양이 압도적임.
- **디즈니+**: '타겟 집중' 전략. 자사 IP를 활용한 가족 및 어린이 중심의 라이브러리 구성이 뚜렷함.
- 본 분석을 통해 OTT 플랫폼마다 고유한 타겟팅 전략이 존재함을 정량적으로 확인했습니다.
